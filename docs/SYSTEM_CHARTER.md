# System Charter

The engine preserves conversation history available to an authorized user across AI platforms. It records evidence before interpretation and separates platform observation from shared capture, verification, and storage behavior.

Phase 1 supports an explicit user-initiated capture of one open ChatGPT conversation. Batch capture, derived knowledge, cloud synchronization, deployment, and remote telemetry are out of scope.

The code repository and private archive are separate security boundaries. Sensitive captures must never be written into or committed from the code repository.
